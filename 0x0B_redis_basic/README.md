# Redis basic

Use Redis from Python for basic set/get operations and a tiny cache layer.

Python 3.9. pycodestyle 2.5. Start redis-server before running the scripts.

## Tasks

0. Writing strings to Redis: Cache.store saves data under a random key.
1. Reading from Redis: Cache.get restores the original type with fn.
2. Incrementing values: count_calls tracks Cache.store calls in Redis.
3. Storing lists: call_history keeps inputs and outputs in Redis lists.
